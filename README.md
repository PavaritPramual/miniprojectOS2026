# CoreSpace — ดูว่าไฟล์และโฟลเดอร์ใดใช้พื้นที่มาก

กลุ่ม **ผู้ก้าวข้ามโชคชะตาด้วยมือของตัวเอง**

- นายศรัณย์ พาพรชัย — 673380515-5
- นายปวริศช์ ประมวล — 673380278-9
- นายธีรเมธ สายคำ — 673380273-9

นำเสนอวันที่ **9 ตุลาคม 2569 เวลา 13:00 น.** ใช้เวลา 5–10 นาที

งานนี้ทำเว็บให้ผู้ใช้เลือกโฟลเดอร์ แล้วเห็นว่าไฟล์และโฟลเดอร์ข้างในใช้พื้นที่เท่าไร ฝั่งซ้ายแสดงโฟลเดอร์เป็นกิ่งที่กางและพับได้ ฝั่งขวาแสดงรายการและขนาด เพื่อช่วยหาโฟลเดอร์ที่ใช้พื้นที่มาก

ทำงานทั้งหมดบน **คอม Windows เครื่องเดียว** ได้ ทั้งเขียนโปรแกรม เปิดเว็บ และนำเสนอ คำว่า “เครื่องเดโม” ในเอกสารเก่าหมายถึงคอมที่ใช้เปิดงานให้อาจารย์ดู ไม่ได้หมายถึงต้องหาเครื่องเพิ่ม

ระบบส่งงานใช้แนวทางเดียว: **C ใน Ubuntu WSL อ่านไฟล์ → Python บน Windows วัดพื้นที่และเก็บผล → เว็บแสดง tree และตาราง** ไม่ทำ benchmark เปรียบเทียบกับต้นแบบ ไม่ต้องวัดความเร็วหรือหน่วยความจำเพื่อส่งงาน ข้อมูลตัวอย่างใช้ตรวจการเชื่อมระหว่างรอ C เท่านั้น

## เปิดโปรแกรมบน Windows

ใช้ Windows ที่ติดตั้ง Python 3.10 ขึ้นไป เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วพิมพ์:

```powershell
.\tools\start.ps1
```

เปิด `http://127.0.0.1:8080` ในเบราว์เซอร์ ปิดด้วย Ctrl+C เว็บใหม่เก็บ Vue และ CSS ไว้ในโปรเจกต์ จึงไม่ต้องใช้อินเทอร์เน็ตโหลดส่วนแสดงผล ปุ่ม Scan อ่านไฟล์จริงต้องตั้งโปรแกรม C ก่อน

ถ้าคำสั่งไม่พบ Python ให้ระบุตำแหน่งที่ติดตั้งจริง ตัวอย่างด้านล่างต้องเปลี่ยน path ให้ตรงเครื่อง:

```powershell
.\tools\start.ps1 -PythonPath 'C:\Python312\python.exe'
```

เพิ่ม `-CheckOnly` เพื่อเช็กก่อนเปิด เมื่อต่อ C ให้เพิ่ม `-ScannerWslPath` พร้อมตำแหน่งโปรแกรมใน Ubuntu ดูคำสั่งและขั้นตอนส่งให้เพื่อนใน [คู่มือส่วนปวริศช์](docs/PAVARIT_HANDOFF.md) หรือเปิดโดยตรงด้วย `python main.py` เมื่อเรียก Python ได้อยู่แล้ว

### เปิดระบบ C จริง

ใน Ubuntu เข้าโฟลเดอร์โปรเจกต์ แล้วรัน `make -C scanner` และ `make -C scanner install` โปรแกรมจะอยู่ที่ `~/.local/bin/diskviz-scan` ดู path เต็มด้วย `readlink -f ~/.local/bin/diskviz-scan` แล้วเปิดจาก PowerShell:

```powershell
.\tools\start.ps1 -PythonPath 'C:\ตำแหน่งที่ติดตั้ง\python.exe' -ScannerWslPath '/home/ชื่อผู้ใช้/.local/bin/diskviz-scan'
```

เปลี่ยนตำแหน่ง Python และชื่อผู้ใช้ Ubuntu ให้ตรงเครื่อง เปิด `http://127.0.0.1:8080` แล้วกรอกโฟลเดอร์ Windows และกด Scan โดยไม่ใช้ `/?mock=1`

## ตรวจงานของปวริศช์

```powershell
python tools/run_checks.py
python tools/run_checks.py --wsl
```

คำสั่งแรกตรวจ Python/API ส่วนคำสั่งที่เพิ่ม `--wsl` ตรวจโปรแกรมจำลองใน Ubuntu ด้วย ต้องมี Ubuntu พร้อม Python 3 และโฟลเดอร์ทดสอบ หากยังไม่มี ให้สร้างครั้งแรกด้วย `.\tools\prepare_demo_fixture.ps1` หาก `python` ไม่อยู่ใน PATH ให้ใช้ตำแหน่งเต็มของ `python.exe` ตามคู่มือ

ผลบันทึกใน `docs/results/backend-tests.txt` ฐานข้อมูลทดสอบแยกจากผลสแกนใช้งานจริง [ผลเดิมวันที่ 4 ต.ค.](docs/results/archive/backend-tests-2026-10-04.txt) เก็บเป็นประวัติ ขั้นถัดไปคือรับ C ต่อหน้าเว็บ แล้วตรวจจำนวนรายการ ขนาด การยกเลิก และข้อผิดพลาดตามคู่มือ
