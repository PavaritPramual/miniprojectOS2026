# CoreSpace — ดูว่าไฟล์และโฟลเดอร์ใดใช้พื้นที่มาก

กลุ่ม **ผู้ก้าวข้ามโชคชะตาด้วยมือของตัวเอง**

- นายศรัณย์ พาพรชัย — 673380515-5
- นายปวริศช์ ประมวล — 673380278-9
- นายธีรเมธ สายคำ — 673380273-9

นำเสนอวันที่ **9 ตุลาคม 2569 เวลา 13:00 น.** ใช้เวลา 5–10 นาที

งานนี้ทำเว็บให้ผู้ใช้เลือกโฟลเดอร์ แล้วเห็นว่าไฟล์และโฟลเดอร์ข้างในใช้พื้นที่เท่าไร ฝั่งซ้ายแสดงโฟลเดอร์เป็นกิ่งที่กางและพับได้ ฝั่งขวาแสดงรายการและขนาด เพื่อช่วยหาโฟลเดอร์ที่ใช้พื้นที่มาก

ทำงานทั้งหมดบน **คอม Windows เครื่องเดียว** ได้ ทั้งเขียนโปรแกรม เปิดเว็บ และนำเสนอ คำว่า “เครื่องเดโม” ในเอกสารเก่าหมายถึงคอมที่ใช้เปิดงานให้อาจารย์ดู ไม่ได้หมายถึงต้องหาเครื่องเพิ่ม

ส่วนอ่านไฟล์ตามแผนจะเขียนด้วยภาษา C และรันผ่าน WSL ซึ่งเป็นเครื่องมือเปิด Linux ภายใน Windows เพื่อใช้คำสั่งอ่านไฟล์ตามแนวทางวิชา ส่วน Python ทำหน้าที่ส่งข้อมูลให้เว็บ รายละเอียดนี้อ่านเพิ่มได้เมื่อเริ่มทำส่วนของตัวเอง

## ตอนนี้มีอะไรแล้ว

| ส่วนงาน | สถานะ | คนที่ทำต่อ |
| --- | --- | --- |
| Python รับข้อมูลและส่งให้เว็บ | รับข้อมูลทีละบรรทัด เก็บผลใน SQLite วัดพื้นที่จาก Windows ส่งรายการทีละ 50 และยกเลิกงานได้ ตรวจข้อมูลทดสอบ 10,000 ไฟล์ครบ | ปวริศช์ต่อ C จริงและเก็บผลหลังรวมงาน |
| โปรแกรมอ่านไฟล์ภาษา C | ส่วนเชื่อม WSL ตรวจด้วยโปรแกรมจำลองแล้ว ยังต้องรับ C มาเชื่อมจริง | ศรัณย์ |
| หน้าเว็บ | ต้นแบบเปิดได้ แต่ปุ่มยังเรียก API เก่า ต้องต่อ API ใหม่และตรวจปุ่มให้ครบ | ธีรเมธ |
| เวลาและหน่วยความจำ | เครื่องมือวัดพร้อมและตรวจการทำงานด้วยโปรแกรมจำลองแล้ว ยังไม่มีผลของ C จริงหรือทั้งไดรฟ์ | ปวริศช์หลังรวมงาน |

ส่วน Python ผ่าน **21 ข้อทดสอบ** รวม HTTP บนเครื่องนี้ การแบ่งหน้า การเปิดผลเดิม และการหยุดโปรแกรมจำลองใน Ubuntu ดู [หลักฐานทดสอบ](docs/results/backend-tests.txt) และ [รายละเอียดผลที่ตรวจได้](docs/PAVARIT_REPORT_NOTES.md) ผลนี้ยังไม่ยืนยันโปรแกรม C ของกลุ่มหรือหน้าเว็บใหม่

ธีรเมธเริ่มเชื่อมเว็บได้ทันทีด้วย `source: "sample"` ตาม [รูปแบบข้อมูลร่วม](docs/CONTRACT.md) ข้อมูลและขนาดในโหมดนี้เป็นค่าจำลอง หากไม่ระบุ `source` Python จะเรียก C ผ่าน WSL และแจ้งข้อผิดพลาดเมื่อยังไม่ได้ตั้งค่า ตัวเลขพื้นที่บางตัวของเว็บต้นแบบเดิมยังมาจากสูตรประมาณ

มี [เครื่องมือสร้างโฟลเดอร์ไว้ลองโปรแกรม](tools/prepare_demo_fixture.ps1) แล้ว ประกอบด้วยไฟล์ 64 รายการและโฟลเดอร์ 13 รายการ รวมตัวอย่างชื่อไทย โฟลเดอร์หลายชั้น และโฟลเดอร์ที่มีลูก 60 รายการ

## เปิดโปรแกรมบน Windows

ใช้ Windows ที่ติดตั้ง Python 3.10 ขึ้นไป เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วพิมพ์:

```powershell
.\tools\start.ps1
```

เปิด `http://127.0.0.1:8080` ในเบราว์เซอร์ ปิดด้วย Ctrl+C หน้าเว็บที่เปิดยังเป็นต้นแบบและต้องใช้อินเทอร์เน็ตโหลดส่วนแสดงผลบางส่วน

ถ้าคำสั่งไม่พบ Python ให้ระบุตำแหน่งที่ติดตั้งจริง ตัวอย่างด้านล่างต้องเปลี่ยน path ให้ตรงเครื่อง:

```powershell
.\tools\start.ps1 -PythonPath 'C:\Python312\python.exe'
```

เพิ่ม `-CheckOnly` เพื่อเช็กก่อนเปิด เมื่อต่อ C ให้เพิ่ม `-ScannerWslPath` พร้อมตำแหน่งโปรแกรมใน Ubuntu ดูคำสั่งและขั้นตอนส่งให้เพื่อนใน [คู่มือส่วนปวริศช์](docs/PAVARIT_HANDOFF.md) หรือเปิดโดยตรงด้วย `python main.py` เมื่อเรียก Python ได้อยู่แล้ว

## ตรวจงานของปวริศช์

```powershell
python tools/run_checks.py
python tools/run_checks.py --wsl
```

คำสั่งแรกตรวจ Python/API ส่วนคำสั่งที่เพิ่ม `--wsl` ตรวจโปรแกรมจำลองใน Ubuntu ด้วย ต้องมี Ubuntu พร้อม Python 3/GNU time และโฟลเดอร์ทดสอบ หากยังไม่มี ให้สร้างครั้งแรกด้วย `.\tools\prepare_demo_fixture.ps1` หาก `python` ไม่อยู่ใน PATH ให้ใช้ตำแหน่งเต็มของ `python.exe` ตามคู่มือ

ผลบันทึกใน `docs/results/backend-tests.txt` ฐานข้อมูลทดสอบแยกจากผลสแกนใช้งานจริง ขั้นถัดไปคือรับ C ต่อหน้าเว็บ ตรวจการใช้งานจริง แล้วเก็บตัวเลขบนชุดเดียวกันด้วย `tools/benchmark_backend.py` ตามคู่มือ
