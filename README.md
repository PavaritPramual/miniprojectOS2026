# CoreSpace

### ดูว่าไฟล์และโฟลเดอร์ใดใช้พื้นที่มาก

เว็บสำหรับสำรวจพื้นที่ไฟล์บน **Windows** เลือกโฟลเดอร์แล้วดูเป็นเมืองไฟล์ คลิกอาคารเพื่อดูชื่อ ขนาด และเปิดตำแหน่ง ใช้มุมมองรายการเมื่อต้องการดูเป็นตาราง

*ภาพจาก C อ่านไฟล์จริงในโฟลเดอร์ `static` ของโปรเจกต์บน Windows กดภาพเพื่อดูขนาดเต็ม*

## ใช้ทำอะไรได้บ้าง

- สำรวจเมืองหรือรายการทีละมุมมอง คลิกเลือกแล้วชื่อ ขนาด และคำสั่งค้างอยู่ด้านข้าง
- เข้าโฟลเดอร์ผ่านย่านและย้อนกลับผ่านเส้นทางด้านบน หมุน/ลาก/ขยายเมืองและเปลี่ยนเป็นแผนที่ได้
- ค้นชื่อหรือ path ในผลสแกนทั้งชุด พร้อมจำนวนที่พบและบันทึกการทำงาน โหลดผลค้นหา 50 รายการต่อหน้า
- โหลดรายการครั้งละ 50 รายการ แล้วกดแสดงเพิ่มเติม หรือเปิดผลล่าสุดของโฟลเดอร์จากฐานข้อมูลได้
- ดู **Logical Size** หรือขนาดเนื้อหาไฟล์ และ **Allocated Size** หรือพื้นที่ที่ Windows รายงานว่าไฟล์ใช้
- ดูจำนวนรายการและบันทึกการทำงานระหว่างสแกน ยกเลิกงานได้
- ดูเหตุผลที่อ่านไม่ได้หรือข้ามรายการ เช่น ไม่มีสิทธิ์ ถูกล็อก หรือเป็นลิงก์

## เปิดใช้งาน

ต้องมี **Windows Python 3.10 ขึ้นไป** และ **Ubuntu ใน WSL** ที่มี `gcc` กับ `make` หน้าเว็บมี Vue และ CSS ในโปรเจกต์แล้ว ไม่ต้องติดตั้ง Node.js เพื่อเปิดงาน

### 1. เตรียมโปรแกรมอ่านไฟล์ใน Ubuntu

เปิด Ubuntu แล้วเข้าโฟลเดอร์โปรเจกต์ เปลี่ยน path ตัวอย่างให้ตรงกับที่เก็บงาน:

```bash
cd /mnt/d/path/to/miniprojectOS2026
make -C scanner
make -C scanner install
readlink -f ~/.local/bin/diskviz-scan
```

หากยังไม่มี compiler ให้ติดตั้ง `build-essential` ก่อน คำสั่งสุดท้ายจะแสดงตำแหน่งโปรแกรม เช่น `/home/student/.local/bin/diskviz-scan` ให้นำไปใช้ในขั้นต่อไป

### 2. เปิดเซิร์ฟเวอร์บน Windows

เปิด PowerShell ที่โฟลเดอร์โปรเจกต์ แล้วเปลี่ยนตำแหน่ง Python และ C ในตัวอย่างให้ตรงเครื่อง:

```powershell
.\tools\start.ps1 `
  -PythonPath 'C:\Python312\python.exe' `
  -ScannerWslPath '/home/student/.local/bin/diskviz-scan'
```

ถ้าเรียก `python` หรือ `py` ได้อยู่แล้ว สามารถละ `-PythonPath` ได้ เพิ่ม `-CheckOnly` เมื่อต้องการตรวจการตั้งค่าก่อนเปิด

### 3. เลือกโฟลเดอร์แล้วกด Scan

เปิด **http://127.0.0.1:8080** กรอกตำแหน่งโฟลเดอร์ Windows แล้วกด **Scan** ปิดเซิร์ฟเวอร์ด้วย **Ctrl+C**

เลือกอาคารเพื่อดูชื่อและขนาด ค้นหาไฟล์ที่หาในเมืองไม่เจอ หรือสลับเป็น **รายการ** เพื่อดูตาราง ปุ่ม **เปิดตำแหน่ง** เปิดไฟล์หรือโฟลเดอร์ใน Explorer และ **เปิดผลล่าสุด** ใช้ดูผลที่บันทึกไว้ ผลเดิมไม่เปลี่ยนตามไฟล์ในเครื่อง ต้องสแกนใหม่เมื่อต้องการข้อมูลล่าสุด

ถ้าไม่ได้ตั้ง C โปรแกรมจะแจ้งข้อผิดพลาด ไม่สลับไปใช้ข้อมูลตัวอย่างเอง ดูตัวเลือกและวิธีเปิดเพิ่มเติมใน [คู่มือปวริศช์](docs/PAVARIT_HANDOFF.md)

## ทำงานอย่างไร

**C ใน Ubuntu WSL → Python บน Windows → เว็บในเบราว์เซอร์**

1. C ใช้ POSIX API เช่น `opendir`, `readdir` และ `lstat` อ่านรายการและ metadata แล้วส่งข้อมูลให้ Python ผ่าน stdout pipe ทีละบรรทัด
2. Python ใช้ `GetCompressedFileSizeW` ของ Windows วัดพื้นที่ รวมยอดโฟลเดอร์ และเก็บผลใน SQLite
3. เว็บเรียก Python ผ่าน HTTP เพื่อขอสถานะ รายการ และค้นผลที่บันทึกไว้ จึงไม่ต้องโหลดผลทั้งไดรฟ์เข้าหน้าเว็บพร้อมกัน

เนื้อหา OS ที่ใช้คือระบบไฟล์และ metadata, process, pipe และการยกเลิกด้วย signal หน้าใช้งานรับผลจาก C จริงและปฏิเสธผล sample ข้อมูลจำลองใน backend ใช้เฉพาะชุดทดสอบภายใน

## สถานะและข้อจำกัด

ระบบหลัก C → Python → เว็บรวมเข้า main แล้ว ส่วน UX เมืองไฟล์ การแก้รับข้อมูล และสไลด์ล่าสุดอยู่ใน [PR #7](https://github.com/PavaritPramual/miniprojectOS2026/pull/7) ซึ่งยังเปิดรอ merge ณ 12 ตุลาคม 2569

| สิ่งที่ตรวจ | ผลและหลักฐาน |
| --- | --- |
| เมืองและหน้าเว็บผ่าน API จริง | 16 กรณีผ่าน รวม C สแกน 64 ไฟล์/13 โฟลเดอร์ รายการ 50+10 การค้นหา และยกเลิก — [UX UAT](docs/results/UX_CITY_UAT.md) |
| Python backend/search ล่าสุด | 20 ข้อผ่าน รวมรายการซ้ำและไฟล์ path ยาวจริงบน Windows — [ผลแก้ metadata](docs/results/READABLE_FILES_FIX.md) |
| ชุดตรวจ C จริงล่าสุดผ่าน Python | 2 ข้อผ่าน / 1 ข้าม ข้อที่ข้ามคือสแกนทั้งไดรฟ์ — [บันทึกผล](docs/results/readable-fix-real-c.txt) |
| สไลด์สำหรับคลิป | 9 หน้า ตรวจภาพและเว็บเลื่อนหน้าแล้ว — [ผลตรวจสไลด์](docs/results/RECORDING_SLIDES_CHECK.md) |

ตัวเลขแต่ละแถวเป็นชุดตรวจคนละขอบเขต ไม่รวมเป็นจำนวน tests ทั้งระบบ ผลรุ่นก่อนอยู่ใน [บันทึกรวมระบบ](docs/results/REAL_SCANNER_INTEGRATION.md)

- ผลที่อ่านไม่ครบแสดง **ผลบางส่วน** พร้อมเหตุผล `0` หมายถึงวัดได้ศูนย์ ส่วน `null` คือยังไม่ทราบหรือวัดไม่ได้
- ข้าม symbolic link/junction เพื่อป้องกันการเดินวน และแสดงเหตุผลที่ข้าม
- ป้ายชื่อไฟล์เล็กแสดงไม่เกิน 12 รายการต่อภาพ รายการอื่นค้นหาและเลือกดูชื่อเต็มได้ พื้นที่ฐานใช้เทียบขนาด ความสูงเป็นสเกล log หน้าต่างเป็นการตกแต่ง
- ยอดโฟลเดอร์เป็นผลรวมไฟล์ที่อ่านได้ อาจนับ hard link ซ้ำ และไม่เท่าพื้นที่ใช้ทั้งหมดของไดรฟ์
- ยังไม่ยืนยันผลสแกนทั้งไดรฟ์ที่จบครบหรือทุกกรณีสิทธิ์ NTFS ต้นเหตุที่ C ส่งรายการซ้ำยังต้องตรวจหากเกิดอีก

ไม่มีงาน benchmark หรือการกล่าวอ้างว่าเร็วกว่าเดิม

เครื่องมือ `tools/prepare_demo_fixture.ps1 -Target <ตำแหน่งใหม่> -VariedSizes` มีไว้สร้างไฟล์ทดสอบภายใน เครื่องมือสแกนจะอ่านไฟล์เหล่านั้นจริง หน้าเว็บไม่มีโหมดข้อมูลสมมติ
