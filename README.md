# CoreSpace — ดูว่าไฟล์และโฟลเดอร์ใดใช้พื้นที่มาก

กลุ่ม **ผู้ก้าวข้ามโชคชะตาด้วยมือของตัวเอง**

- นายศรัณย์ พาพรชัย — 673380515-5
- นายปวริศช์ ประมวล — 673380278-9
- นายธีรเมธ สายคำ — 673380273-9

นำเสนอวันที่ **9 ตุลาคม 2569 เวลา 13:00 น.** ใช้เวลา 5–10 นาที

งานนี้ทำเว็บให้ผู้ใช้เลือกโฟลเดอร์ แล้วเห็นว่าไฟล์และโฟลเดอร์ข้างในใช้พื้นที่เท่าไร ฝั่งซ้ายแสดงโฟลเดอร์เป็นกิ่งที่กางและพับได้ ฝั่งขวาแสดงรายการและขนาด เพื่อช่วยหาโฟลเดอร์ที่ใช้พื้นที่มาก

ทำงานทั้งหมดบน **คอม Windows เครื่องเดียว** ได้ ทั้งเขียนโปรแกรม เปิดเว็บ และนำเสนอ คำว่า “เครื่องเดโม” ในเอกสารเก่าหมายถึงคอมที่ใช้เปิดงานให้อาจารย์ดู ไม่ได้หมายถึงต้องหาเครื่องเพิ่ม

ส่วนอ่านไฟล์ตามแผนจะเขียนด้วยภาษา C และรันผ่าน WSL ซึ่งเป็นเครื่องมือเปิด Linux ภายใน Windows เพื่อใช้คำสั่งอ่านไฟล์ตามแนวทางวิชา ส่วน Python ทำหน้าที่ส่งข้อมูลให้เว็บ รายละเอียดนี้อ่านเพิ่มได้เมื่อเริ่มทำส่วนของตัวเอง

## ตอนนี้มีอะไรแล้ว

มีเว็บต้นแบบที่ใช้ Python อ่านไฟล์บน Windows และแสดงโฟลเดอร์แล้ว แต่ยังต้องตรวจปุ่มและการแสดงรายการให้ครบ ส่วนอ่านไฟล์ด้วย C และการวัดพื้นที่ที่ไฟล์ใช้จริงยังเป็นงานที่ต้องทำต่อ ตัวเลขบางตัวในต้นแบบยังมาจากสูตรประมาณ

มี [เครื่องมือสร้างโฟลเดอร์ไว้ลองโปรแกรม](tools/prepare_demo_fixture.ps1) แล้ว ประกอบด้วยไฟล์ 64 รายการและโฟลเดอร์ 13 รายการ รวมตัวอย่างชื่อไทย โฟลเดอร์หลายชั้น และโฟลเดอร์ที่มีลูก 60 รายการ

## เปิดเว็บต้นแบบ

ใช้ Windows ที่ติดตั้ง Python 3.10 ขึ้นไป เปิด PowerShell ในโฟลเดอร์โปรเจกต์แล้วพิมพ์:

```powershell
python main.py
```

เปิด `http://localhost:8080` ในเบราว์เซอร์ เว็บต้นแบบยังต้องใช้อินเทอร์เน็ตโหลดส่วนแสดงผลบางส่วน หากเครื่องไม่รู้จักคำสั่ง `python` ต้องตรวจการติดตั้งก่อน
