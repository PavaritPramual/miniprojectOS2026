# CoreSpace — บันทึกงานที่มีและงานที่ต้องทำต่อ

หน้านี้บอกสถานะของต้นแบบ ส่วนหน้าที่ของสมาชิกอ่านได้ที่ [แผนรายคน](PROJECT_PLAN.md)

## สิ่งที่มีในต้นแบบ

| ส่วน | ตอนนี้มีอะไร | ยังต้องตรวจอะไร |
| --- | --- | --- |
| หน้าเว็บ | กิ่งโฟลเดอร์ ตารางไฟล์ และปุ่มสแกน/เปิดตำแหน่งไฟล์ | ต้องลองปุ่มให้ครบ และยังต้องใช้อินเทอร์เน็ตโหลดส่วนแสดงผลบางส่วน |
| การอ่านไฟล์ | ใช้ Python เรียกความสามารถของ Windows | ส่วนอ่านไฟล์ด้วย C ตามแผนยังต้องพัฒนา |
| ขนาดไฟล์ | มีขนาดเนื้อหา ส่วนพื้นที่บนดิสก์ใช้สูตรประมาณ | ต้องเปลี่ยนเป็นค่าที่อ่านจาก Windows จริง |
| จำนวนชั้นของโฟลเดอร์ | การแก้ที่ค้างในโค้ดเมื่อ 30 ก.ย. ตั้งไว้ 6 ชั้น | ต้องแก้ให้ดูรายการที่ลึกกว่านั้นได้ตามแผน |
| การวัดความเร็ว | มีเครื่องมือจับเวลาของต้นแบบ | ยังไม่มีผลวัดของรุ่นที่ใช้ C |

เอกสารเก่าบางหน้าระบุว่าเร็วมาก ใช้หน่วยความจำน้อย หรือวัดขนาดแม่นยำ โดยไม่มีผลที่ใช้ตรวจสอบแนบ ทีมควรใช้ผลที่ทดลองจริงประกอบรายงานและสไลด์

## งานที่จะทำต่อ

ศรัณย์ทำส่วน C ที่อ่านไฟล์ ปวริศช์ทำส่วนเชื่อมและรวมขนาด ธีรเมธทำหน้าเว็บกับสไลด์ ใช้ [ตารางวันเดียว](ONE_DAY_PLAN.md) ดูลำดับส่งงาน และ [สิ่งที่เว็บต้องทำได้](SPEC.md) ตรวจว่ายังขาดอะไร
