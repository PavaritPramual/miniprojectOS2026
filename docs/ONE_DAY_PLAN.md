# ตารางทำ CoreSpace ในวันเดียว

ตั้งเวลาทำงาน **09:00–21:00 น.** ให้ทั้งสามคนเริ่มพร้อมกันได้ ข้อตกลงเรื่องหน้าที่อยู่ใน [แผนรายคน](PROJECT_PLAN.md) ส่วนชื่อข้อมูลที่ต้องใช้ร่วมกันเตรียมไว้ใน [คู่มือเชื่อมโปรแกรม](CONTRACT.md) แล้ว

เป้าหมายคือมีโปรแกรมที่เปิดใช้และนำเสนอได้ในคอม Windows เครื่องเดียว ระยะเวลานี้เป็นเป้าหมายทำงาน หากยังมีส่วนที่ลองแล้วไม่ผ่าน ให้บอกตามจริงและแก้ส่วนนั้นก่อนถือว่าเสร็จ

## ก่อนเริ่ม

เปิดเว็บต้นแบบให้ได้ และให้ศรัณย์ลองรัน C ผ่าน Ubuntu ใน WSL ซึ่งเป็น Linux ที่เปิดอยู่ภายใน Windows เครื่องเดียวกัน

ผลตรวจเมื่อ 30 ก.ย. พบว่า Ubuntu มีเครื่องมือสร้างโปรแกรม C และอ่านไดรฟ์ D ได้แล้ว เวลาสั่งงานให้ระบุ `wsl -d Ubuntu` เพราะเครื่องนี้ตั้ง Linux ตัวอื่นเป็นค่าเริ่มต้น ส่วน PowerShell ที่ใช้ตรวจยังไม่รู้จักคำสั่ง `python` หรือ `py` ปวริศช์จึงต้องตรวจว่าจะเปิด Python บน Windows ด้วยคำสั่งใด

มีโฟลเดอร์สำหรับลองโปรแกรมเตรียมไว้ที่ `fixtures/generated/demo` ในเครื่องปัจจุบัน หากเพื่อนดึงงานไปอีกเครื่อง ให้ใช้ [เครื่องมือสร้างชุดตัวอย่าง](../tools/prepare_demo_fixture.ps1) สร้างขึ้นใหม่

## ทำอะไรก่อนและหลัง

| **09:15–15:00** | เขียนและลองส่วนอ่านไฟล์ให้ได้ข้อมูลตามตัวอย่าง | ทำและลองส่วนรับส่งข้อมูลกับการรวมขนาด โดยใช้ข้อมูลตัวอย่างแทน C ก่อน | ทำและลองกิ่งโฟลเดอร์ ตาราง และปุ่มโดยใช้ข้อมูลตัวอย่าง |

**รวมงานช่วงท้ายครั้งเดียว เริ่ม 15:00:** ศรัณย์ส่งส่วนอ่านไฟล์ให้ปวริศช์ จากนั้นปวริศช์เชื่อมข้อมูลให้ธีรเมธ ทั้งสามคนเผื่อ 3 ชั่วโมงไว้ลองและแก้ปัญหาด้วยกัน บอกไฟล์ วิธีเปิด และปัญหาที่เหลือในข้อความเดียวได้

ระหว่างทำแยกกัน ใช้ชื่อและรูปแบบข้อมูลตามตัวอย่างเดิม หากต้องเปลี่ยนข้อมูลที่ส่งให้กันให้แจ้งเพื่อนทันที ส่วนโครงรายงานและสไลด์เริ่มร่างไว้ก่อนได้

ตอนรวมงาน ให้ทำเส้นทางนี้ให้ใช้ได้ก่อน: **กดปุ่ม → เรียก C → อ่านไฟล์ → ส่งกลับ → แสดงบนเว็บ** แล้วจึงลองกรณีอื่น หากยังไม่ผ่านตอน 18:00 ต้องแก้ส่วนนี้ก่อนนำผลไปใส่รายงาน

## ตอนลองโปรแกรมให้ดูอะไร

- โฟลเดอร์ว่างต้องเปิดได้ และไฟล์ขนาดศูนย์ต้องแสดงศูนย์จริง
- ชื่อไทยและชื่อที่มีช่องว่างต้องอ่านและแสดงได้
- โฟลเดอร์ลึก 8 ชั้นต้องกางไปถึงได้
- โฟลเดอร์ที่มีลูก 60 รายการต้องดูได้ครบ โดยกด “แสดงเพิ่มเติม”
- กดสแกน ยกเลิก และเปิดตำแหน่งไฟล์แล้วได้ผลตามที่ปุ่มบอก
- รายการที่อ่านไม่ได้ต้องแจ้งปัญหา ไม่แสดงว่าใช้พื้นที่ศูนย์
- ลองสแกนทั้งไดรฟ์ตามเป้าหมายในแผนกลุ่ม ระหว่างรอใช้เวลาทำรายงานและสไลด์ จดผลตามจริงหากยังไม่จบหรือเกิดปัญหา

ชุดตัวอย่างที่เตรียมไว้มี 64 ไฟล์และ 13 โฟลเดอร์ ช่วยตรวจเรื่องจำนวนรายการได้ แต่กรณีสิทธิ์อ่านไฟล์ไม่พอและลิงก์ชี้วนต้องลองเพิ่ม

## ปิดงาน

หลัง 18:00 เก็บผลที่รันได้แล้วลงรายงานและสไลด์ ใช้ภาพจริงพร้อมคำอธิบายสั้น ๆ ก่อนจบวันลองเปิดโปรแกรมใหม่และซ้อมพูดสองรอบให้จบใน 5–10 นาที

เวลานำเสนอใช้โฟลเดอร์ขนาดเล็กเพื่อให้รอไม่นาน ส่วนผลทั้งไดรฟ์เปิดจากผลที่สแกนไว้ก่อนบนคอม Windows เครื่องเดียวกัน
