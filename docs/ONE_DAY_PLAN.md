# CoreSpace — แผนลงมือทำให้จบในวันเดียว

**รูปแบบ:** วันทำงานร่วมกัน 09:00–21:00 น. สมาชิกทั้ง 3 คนใช้ [CONTRACT.md](CONTRACT.md) เป็นข้อตกลงเดียวกันและใช้เครื่องที่จะนำเสนอจริง<br>
**เป้าหมายปลายวัน:** เว็บ Windows ใช้ C/POSIX ใน WSL สแกนโฟลเดอร์จริง แสดง tree และตารางที่โหลดลูกทีละ 50 รายการ วัด Logical/Allocated ตาม [SPEC.md](SPEC.md) มีสถานะงาน/ยกเลิก/ข้อผิดพลาด พร้อมผลทดสอบ รายงาน และสไลด์ที่อ้างการรันจริง<br>
**เงื่อนไขเริ่ม:** เครื่องเดโมมี WSL, C compiler, Python และเข้าถึง `/mnt/c` หรือ `/mnt/d` ได้ หากไม่ผ่าน ให้แก้สภาพแวดล้อมก่อนเริ่มนับเวลาพัฒนาวันเดียว

**ผลตรวจเครื่องปัจจุบัน (30 ก.ย.):** `wsl -d Ubuntu` มี `gcc` และอ่าน `/mnt/d` ได้; default WSL distro เป็น `docker-desktop` จึงต้องระบุ `-d Ubuntu` หรือเปลี่ยนค่า default ก่อนรัน C; คำสั่ง `python`/`py` ยังไม่พบใน PATH ของเทอร์มินัลนี้ ต้องหา runtime Windows ที่ใช้กับเดโมให้ได้ก่อนเริ่มจับเวลา

**ชุดทดสอบพร้อมใช้:** รัน [`tools/prepare_demo_fixture.ps1`](../tools/prepare_demo_fixture.ps1) หนึ่งครั้งจาก root ของโปรเจกต์ จะสร้าง `fixtures/generated/demo` โดยไม่ทับของเดิม: 64 regular files, 13 directories รวม root, ชั้นลึก 8, โฟลเดอร์ลูก 60, ชื่อไทย/ช่องว่าง, ไฟล์ 0 ไบต์และ 1 MiB; ได้ตรวจว่า Ubuntu WSL อ่านชุดนี้ได้ครบแล้ว ลิงก์วนให้เลือกสร้างด้วย `-IncludeJunction` เฉพาะเมื่อต้องทดสอบกรณีนั้น

นี่คือแผนเร่งงานของทีม ไม่ใช่หลักฐานว่าฟีเจอร์เสร็จแล้ว ข้อกำหนดและเกณฑ์รับงานยังยึด [SPEC.md](SPEC.md) หากจุดตรวจใดไม่ผ่าน ต้องแจ้งสถานะจริงและไม่ใส่ผลจำลองลงในรายงานหรือเดโม

## ตรวจรับปลายวันแบบสั้น

- จาก checkout ที่รวมงานแล้ว build C ใน WSL และรัน `python main.py` บน Windows ได้
- กด Scan โฟลเดอร์สด; tree เปิดเกิน 6 ชั้นได้; รายการเกิน 50 กด “แสดงเพิ่มเติม” แล้วครบ; Reveal/Cancel แจ้งผลจริง
- Logical ของไฟล์ตัวอย่างตรง metadata; Allocated เทียบ Windows API/Properties; ค่าอ่านไม่ได้เป็น unknown/partial
- ลิงก์หรือรายการอ่านไม่ได้ไม่ทำให้วนและไม่หายเงียบ; เว็บยังตอบสนองระหว่างสแกน
- มีหลักฐานสแกนทั้งไดรฟ์บนเครื่องเดโมจนจบหรือบันทึกสถานะที่ยังไม่ผ่านตามจริง; มีเวลาวัดและข้อจำกัดจริง
- รายงานและสไลด์ 7 หน้าตรงกับโค้ดและผลทดสอบ; ซ้อมครบ 2 รอบใน 5–10 นาที

**ถ้าเวลาไม่พอ:** ให้รักษาเส้นทางหลัก C/POSIX → Python → เว็บและความถูกต้องของตัวเลขก่อน งานสไลด์ใช้เฉพาะฟีเจอร์ที่ผ่านจุดตรวจแล้ว แต่ full-drive, pagination, cancel หรือปุ่มใดที่ไม่ผ่านยังถือว่า **ไม่ผ่าน SPEC** ต้องบันทึกตรง ๆ ไม่ประกาศว่างานสมบูรณ์
