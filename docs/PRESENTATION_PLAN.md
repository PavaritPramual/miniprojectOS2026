# แผนนำเสนอ CoreSpace

นำเสนอวันที่ **9 ตุลาคม 2569 เวลา 13:00 น.** ใช้เวลา 5–10 นาที ตั้งเป้าซ้อมประมาณ 8 นาที เปิดเว็บจากคอม Windows ที่ใช้ทำงานได้เลย

ให้อาจารย์เห็นสามเรื่อง: โปรแกรมช่วยอะไร ใช้ความรู้ OS ตรงไหน และส่วนที่ทำขึ้นใช้งานได้อย่างไร

## สไลด์ 7 หน้า

| หน้า | คนพูด | เนื้อหาบนสไลด์และคำพูดเริ่มต้น | เวลา |
| --- | --- | --- | --- |
| 1. ทำโปรแกรมนี้เพื่ออะไร | ธีรเมธ | “เราอยากรู้ว่าโฟลเดอร์ไหนใช้พื้นที่มาก จึงทำเว็บให้ดูขนาดและกางดูรายการข้างในได้ครับ” ใส่ภาพหน้าเว็บหนึ่งภาพ | 45 วินาที |
| 2. เกี่ยวกับวิชา OS อย่างไร | ศรัณย์ | “โปรแกรมต้องขอรายชื่อและขนาดไฟล์จากระบบปฏิบัติการ เราใช้ C อ่านโฟลเดอร์และข้อมูลของไฟล์ครับ” แสดงคำสั่งที่ใช้จริงพร้อมคำอธิบายภาษาไทย | 55 วินาที |
| 3. โปรแกรมทำงานอย่างไร | ศรัณย์ | แสดงลำดับ “ผู้ใช้กดสแกน → Python เรียก C → C อ่านไฟล์ → Python รวมข้อมูล → เว็บแสดงผล” บอกว่า WSL เปิด Linux ภายใน Windows เครื่องเดียวกัน | 1 นาที |
| 4. ตัวเลขขนาดหมายถึงอะไร | ปวริศช์ | “ขนาดเนื้อหาไฟล์กับพื้นที่ที่ใช้บนดิสก์อาจไม่เท่ากันครับ” ใช้ไฟล์ที่ตรวจจริงหนึ่งไฟล์ประกอบ และบอกว่ายอดที่รวมได้อาจไม่เท่าพื้นที่ใช้ทั้งไดรฟ์ | 1 นาที |
| 5. วิธีใช้เว็บ | ธีรเมธ | “เลือกโฟลเดอร์ กดสแกน แล้วกางดูรายการได้ ถ้ารายการเยอะให้กดแสดงเพิ่มเติมครับ” ชี้ตำแหน่งปุ่มจากภาพ | 55 วินาที |
| 6. เปิดโปรแกรมให้ดู | ธีรเมธ | เลือกโฟลเดอร์ตัวอย่าง กดสแกน กางโฟลเดอร์ ดูขนาด และเปิดตำแหน่งไฟล์ จากนั้นเปิดผลทั้งไดรฟ์ที่สแกนเตรียมไว้หากมีผลแล้ว | 2 นาที |
| 7. ผลที่ลองและข้อจำกัด | ปวริศช์ | บอกจำนวนไฟล์ เวลาที่ใช้ และปัญหาที่พบจากการลองจริง เช่น บางไฟล์ไม่มีสิทธิ์อ่าน สรุปว่างานช่วยให้หาโฟลเดอร์ขนาดใหญ่ได้อย่างไร | 1 นาที 10 วินาที |

รวมเนื้อหาประมาณ 7 นาที 45 วินาที เหลือเวลาเปลี่ยนคนพูดในเป้า 8 นาที หากอาจารย์ให้เพียง 5 นาที ให้ลดรายละเอียดหน้า 3–4 และเปิดโปรแกรมให้ดูประมาณ 1 นาที

## เตรียมก่อนพูด

1. เปิดโปรแกรมบนคอมที่จะใช้ให้เรียบร้อย แล้วลองสแกนโฟลเดอร์ตัวอย่างหนึ่งรอบ
2. ใช้โฟลเดอร์เล็กสำหรับกดให้ดูสด จะได้ไม่เสียเวลารอทั้งไดรฟ์
3. เตรียมภาพหรือวิดีโอจากการรันจริงไว้ หากเปิดสดมีปัญหาให้บอกว่าเป็นผลที่บันทึกไว้ก่อน
4. ทุกคนลองพูดส่วนของตน แล้วซ้อมต่อกันสองรอบ

## รายงานเขียนเรื่องอะไรบ้าง

ปวริศช์รวมรายงาน ศรัณย์ส่งคำอธิบายส่วนอ่านไฟล์ และธีรเมธส่งภาพกับวิธีใช้เว็บ

รายงานเรียงจากปัญหาที่ต้องการแก้ เป้าหมาย หน้าที่ของแต่ละส่วน คำสั่งระบบปฏิบัติการที่ใช้ วิธีรวมขนาด วิธีใช้งาน ผลที่ทดลอง และข้อจำกัด ชื่อคำสั่งที่เป็นภาษาอังกฤษให้เขียนคำอธิบายภาษาไทยกำกับ

ข้อกำหนดจาก [เอกสารรายวิชา](../../LectureDoc/Operating_Systems_and_System_Calls_Syllabus.docx.pdf) เป็นแหล่งอ้างอิงเรื่องงานส่ง ส่วนการแบ่ง 7 สไลด์และเวลาของแต่ละคนเป็นแผนที่กลุ่มเลือกใช้
