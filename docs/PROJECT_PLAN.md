# หน้าที่ของสมาชิก CoreSpace

เป้าหมายร่วมกันคือ **เปิดเว็บบน Windows เลือกโฟลเดอร์ แล้วดูรายการและขนาดได้ถูกต้อง** ทุกคนต้องอธิบายได้ว่าส่วนของตัวเองทำงานอย่างไร ใช้ C → Python → เว็บแนวทางเดียว ตรวจความถูกต้องและการใช้งาน ไม่ทำ benchmark เปรียบเทียบความเร็วหรือวัดหน่วยความจำ

ใช้คอม Windows เครื่องเดียวทำงานและนำเสนอได้ อ่านเวลาส่งต่องานใน [แผนวันเดียว](ONE_DAY_PLAN.md) และสิ่งที่โปรแกรมต้องทำได้ใน [ข้อกำหนดงาน](SPEC.md)

## ใครทำอะไร

| สมาชิก | งานหลัก | สิ่งที่ส่งให้เพื่อน | ถือว่าเสร็จเมื่อ |
| --- | --- | --- | --- |
| **ศรัณย์** | ทำโปรแกรมภาษา C สำหรับอ่านชื่อ ชนิด และขนาดไฟล์ในโฟลเดอร์ | โปรแกรมที่รันได้ วิธีรัน และตัวอย่างรายการที่อ่านออกมา | อ่านโฟลเดอร์ตัวอย่างได้ครบ แจ้งรายการที่อ่านไม่ได้ และปวริศช์รับข้อมูลไปใช้ได้ |
| **ปวริศช์** | ทำให้เว็บสั่งโปรแกรม C ได้ รวมขนาดไฟล์ และส่งผลกลับให้เว็บ | ส่วนเชื่อมโปรแกรมที่ใช้งานได้ ตัวเลขที่ตรวจแล้ว และร่างรายงาน | กดสแกนจากเว็บแล้วได้ข้อมูลจริง ขนาดถูกต้อง และธีรเมธนำไปแสดงได้ |
| **ธีรเมธ** | ทำหน้าเว็บให้เลือกโฟลเดอร์ กางรายการ และดูขนาดได้สะดวก พร้อมทำสไลด์ | หน้าเว็บที่ปุ่มทำงาน ภาพหน้าจอ และสไลด์ | เพื่อนลองกดใช้งานได้ รายการไม่หายโดยไม่บอก และเปิดโปรแกรมให้อาจารย์ดูได้ |

## ศรัณย์ทำตามลำดับนี้

1. เปิด Ubuntu ผ่าน WSL บน Windows แล้วลองสร้างและรันโปรแกรม C
2. ให้โปรแกรมรับชื่อโฟลเดอร์ แล้วอ่านชื่อไฟล์และขนาด รวมถึงโฟลเดอร์ย่อย
3. ส่งรายการที่อ่านได้ออกมาทีละรายการตาม [ตัวอย่างข้อมูลจาก C](examples/scan.ndjson) เพื่อให้ปวริศช์ใช้ต่อได้ทันที
4. ถ้าอ่านรายการไหนไม่ได้ ให้บอกว่าเป็นรายการใด อย่าใส่ขนาดเป็นศูนย์แทน
5. ระวังรายการที่เป็นลิงก์ชี้กลับไปโฟลเดอร์เดิม เพื่อไม่ให้โปรแกรมอ่านวนไม่จบ
6. จดว่าคำสั่งอ่านไฟล์ใดเกี่ยวข้องกับวิชา และเตรียมอธิบายหน้าสไลด์ 2–3

รายละเอียดชื่อคำสั่งและรูปแบบข้อมูลอยู่ใน [คู่มือเชื่อมโปรแกรม ข้อ 1](CONTRACT.md#1-c-scanner--python-ndjson)

## ปวริศช์ทำตามลำดับนี้

1. เปิดเว็บใหม่ที่ merge แล้วด้วย Python บน Windows
2. ใช้ข้อมูลตัวอย่างที่เตรียมไว้ทำส่วนส่งข้อมูลให้เว็บก่อน ระหว่างรอโปรแกรมของศรัณย์
3. เมื่อได้โปรแกรม C ให้ Python เรียกโปรแกรมนั้นและรับรายการไฟล์กลับมา
4. ตรวจขนาดเนื้อหาไฟล์ และขอข้อมูลจาก Windows เพื่อวัดพื้นที่ที่ไฟล์ใช้บนดิสก์จริง ถ้าวัดไม่ได้ให้แสดงว่า “ไม่ทราบ”
5. ทำให้การสแกนไม่ขัดขวางการกดใช้เว็บ และให้เว็บขอรายการเพิ่มได้ทีละชุดตาม [ข้อกำหนดงาน](SPEC.md)
6. ลองสแกน จดจำนวน ขนาด และปัญหาที่พบ แล้วรวบรวมรายงาน เตรียมพูดหน้าสไลด์ 4 และ 7

รายละเอียดชื่อคำขอและข้อมูลที่เว็บจะได้รับอยู่ใน [คู่มือเชื่อมโปรแกรม](CONTRACT.md)

## ธีรเมธทำตามลำดับนี้

1. ใช้ [ข้อมูลตัวอย่างสำหรับเว็บ](examples/api.json) ทำหน้าตาและปุ่มได้เลย
2. ฝั่งซ้ายแสดงโฟลเดอร์เป็นกิ่งที่กางและพับได้ ฝั่งขวาแสดงชื่อและขนาดของรายการข้างใน
3. ทำปุ่มสแกน แสดงเพิ่มเติม ยกเลิก และเปิดตำแหน่งไฟล์ ให้มีข้อความบอกเมื่อทำสำเร็จหรือเกิดปัญหา
4. เมื่อปวริศช์ส่งส่วนเชื่อมมาให้ เปลี่ยนจากข้อมูลตัวอย่างเป็นข้อมูลที่อ่านจากเครื่องจริง
5. ลองกดทุกปุ่ม ตรวจชื่อไทย โฟลเดอร์หลายชั้น และโฟลเดอร์ที่มีหลายรายการ
6. เก็บภาพจากงานที่รันจริง ทำสไลด์ตาม [แผนนำเสนอ](PRESENTATION_PLAN.md) และซ้อมพูดหน้า 1, 5, 6
