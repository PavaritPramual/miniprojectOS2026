# ชุดส่งต่อสไลด์ CoreSpace สำหรับอัดคลิป

อัปเดต 12 ตุลาคม 2569 สไลด์ครบ 9 หน้า รวมหน้าปกและขอบคุณ เป้าหมายเวลา 8 นาที เน้น file system, metadata, POSIX API, process, pipe และขนาดไฟล์ ไม่มี benchmark

## เปิดไฟล์ไหน

- [Canva สำหรับแก้ไข](https://www.canva.com/d/C4RnAdA_35Q32Kh) — ชื่อ **CoreSpace — คลิปนำเสนอ OS 8 นาที** รหัส design `DAHXwh4vKRo` ตรวจแล้วเป็น Presentation 1920×1080 ครบ 9 หน้า ข้อความแยกแก้ไขได้ กล่องและลูกศรแยกเป็นชิ้น ส่วนภาพเว็บเป็นภาพผลจริง
- [PowerPoint](CoreSpace-Recording.pptx) — ข้อความ กล่อง ลูกศร และตารางแก้ไขได้ มีบทพูดใน notes ฟอนต์ที่ระบุคือ Sarabun การแสดงผลขึ้นกับฟอนต์ที่เครื่องมี
- [PDF](CoreSpace-Recording.pdf) — สำรองเปิดดูหรือส่งไฟล์ presentation
- เว็บ `/static/presentation.html` — ภาพสไลด์ครบ 9 หน้าและบทพูด เปิดซ้อมในเครื่องได้ ปุ่มก่อนหน้า/ถัดไปและลูกศรบนคีย์บอร์ดใช้เลื่อนหน้า

Canva แปลงจากต้นฉบับและจัดข้อความใหม่ ภาพตัวอย่างที่ตรวจแล้วอ่านได้ทุกหน้า แต่ฟอนต์ไทยบางกล่องเป็นฟอนต์แทน หากต้องการใช้ Sarabun ทั้งชุดให้เลือกข้อความใน Canva แล้วเปลี่ยนฟอนต์พร้อมกัน ก่อนส่งออกให้เปิดเต็มจอตรวจอีกครั้ง

## ภาพและตัวเลขอ้างอิงอะไร

หน้า 2 ใช้ภาพเมืองจาก C อ่านไฟล์จริงในโฟลเดอร์ static ของโปรเจกต์ หน้า 7 ใช้ภาพไฟล์จริงขนาดเล็กที่เลือกแล้วมีชื่อและรายละเอียดค้างอยู่ อ้าง [UX UAT](results/UX_CITY_UAT.md)

หน้า 8 ใช้เมือง/เว็บ 16 กรณีผ่าน Python backend/search ล่าสุด 20 ผ่าน และชุด C จริงล่าสุด 2 ผ่าน/1 ข้าม อ้าง [การแก้ metadata](results/READABLE_FILES_FIX.md) ไม่อ้างว่าสแกนทั้งไดรฟ์จบ ไม่รวมจำนวน tests ต่างชุดเป็นยอดเดียว

## ยังต้องทำก่อนส่งคลิป

1. อัดเสียงตามหน้าที่ข้างบน
2. อัดหน้าจอเดโมจริง 2 นาทีตามบทพูด เปิดเว็บปกติและใช้ C จริง ดูเมือง เลือกอาคาร ค้นหา สลับรายการ แสดงเพิ่มเติม ดูขนาด เปิดตำแหน่ง และเหตุผลที่ข้าม junction
3. แทรกวิดีโอตรงหน้า 7 แทนภาพรอเดโม ตัดเป็น MP4 แนวนอน 16:9 ตรวจเสียงและภาพครบทั้งคลิป
4. เตรียมไฟล์ demo, presentation และรายงานถ้ามีตามที่อาจารย์แจ้ง ยังไม่ได้ตั้งกำหนดส่งหรือช่องทางใหม่เอง
