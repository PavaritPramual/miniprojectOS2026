- [PowerPoint](CoreSpace-Recording.pptx) — ข้อความ กล่อง ลูกศร และตารางแก้ไขได้ มีบทพูดใน notes ฟอนต์ที่ระบุคือ Sarabun การแสดงผลขึ้นกับฟอนต์ที่เครื่องมี
- [PDF](CoreSpace-Recording.pdf) — สำรองเปิดดูหรือส่งไฟล์ presentation

Canva แปลงจากต้นฉบับและจัดข้อความใหม่ ภาพตัวอย่างที่ตรวจแล้วอ่านได้ทุกหน้า แต่ฟอนต์ไทยบางกล่องเป็นฟอนต์แทน หากต้องการใช้ Sarabun ทั้งชุดให้เลือกข้อความใน Canva แล้วเปลี่ยนฟอนต์พร้อมกัน ก่อนส่งออกให้เปิดเต็มจอตรวจอีกครั้ง

## ภาพและตัวเลขอ้างอิงอะไร

หน้า 2 และ 7 ใช้ภาพกราฟจาก C จริงใน WSL ผ่าน Python บน Windows ไม่ใช่ mock ผลสแกนวันที่ 12 ตุลาคมได้ 64 ไฟล์/13 โฟลเดอร์ ไม่มี error/skip ยอด root 2,922,505 ไบต์ `many` 1,873,920 ไบต์และ `large.bin` 1,048,576 ไบต์ ดู [หลักฐานกราฟและข้อจำกัด](SIZE_BARS.md)

หน้า 8 แยก Python 23 ผ่าน/12 ข้ามจาก C 11 ผ่านใน Ubuntu และ browser กราฟ 7 กรณีผ่าน การยกเลิกไดรฟ์ D เป็นผลที่ตรวจไว้ก่อนหน้า ยังไม่มีผลสแกนทั้งไดรฟ์ที่จบครบ ห้ามกล่าวว่าได้ทดสอบทุกสิทธิ์ NTFS หรือว่าสองขนาดต้องต่างกัน

## ยังต้องทำก่อนส่งคลิป

3. แทรกวิดีโอตรงหน้า 7 แทนภาพรอเดโม ตัดเป็น MP4 แนวนอน 16:9 ตรวจเสียงและภาพครบทั้งคลิป
