# สิ่งที่ CoreSpace ต้องทำได้

เอกสารนี้บอกผลที่ผู้ใช้ควรเห็น และสิ่งที่ทีมเลือกทำในโปรเจกต์ ใช้ประกอบ [แผนรายคน](PROJECT_PLAN.md) และ [ตารางทำงานวันเดียว](ONE_DAY_PLAN.md)

**วัตถุประสงค์:** ช่วยให้ผู้ใช้รู้ว่าไฟล์หรือโฟลเดอร์ใดใช้พื้นที่มาก โดยเลือกโฟลเดอร์แล้วดูขนาดและกางดูรายการข้างในผ่านเว็บบน Windows

เอกสารวิชาเป็นแหล่งอ้างอิงเรื่อง C/POSIX และสิ่งที่ต้องส่ง ส่วนการเลือกใช้เว็บ แสดงทีละ 50 รายการ เก็บผลด้วย SQLite และรองรับทั้งไดรฟ์เป็นรายละเอียดที่เลือกไว้ในแผนกลุ่ม ไม่ใช่ข้อกำหนดที่ยืนยันว่าอาจารย์ระบุทุกข้อ

## ใช้คอมอย่างไร

ทำงานและนำเสนอบน **Windows เครื่องเดียว** ได้ ผู้ใช้เปิดเว็บตามปกติ ส่วน C รันผ่าน WSL ซึ่งเป็นเครื่องมือเปิด Linux ภายใน Windows เพื่อใช้คำสั่งอ่านไฟล์ตามแนวทางวิชา

ลำดับการทำงานคือ **กดสแกนบนเว็บ → Python เรียก C → C อ่านรายการไฟล์ → Python รวมผล → เว็บแสดงรายการ**

Python เป็นตัวเชื่อมระหว่างหน้าเว็บกับ C และขอข้อมูลพื้นที่ไฟล์จาก Windows โปรแกรมให้บริการเฉพาะในเครื่องที่เปิดอยู่ ไม่ต้องนำเว็บขึ้นอินเทอร์เน็ต

## ตอนนี้มีอะไรและต้องทำต่ออะไร

| ส่วน | มีอยู่แล้ว | งานต่อ |
| --- | --- | --- |
| หน้าเว็บ | โฟลเดอร์แบบกางได้และตารางรายการ | ตรวจปุ่มและแก้ให้ดูรายการได้ครบ |
| ส่วนอ่านไฟล์ | ต้นแบบใช้ Python อ่านไฟล์บน Windows | ทำส่วน C ตามแนวทางที่วางไว้ |
| ตัวเลขขนาด | มีขนาดเนื้อหาและสูตรประมาณพื้นที่ | อ่านพื้นที่ที่ใช้จริงจาก Windows และบอกเมื่อวัดไม่ได้ |
| การสแกนจำนวนมาก | ต้นแบบรออ่านเสร็จแล้วส่งผลก้อนเดียว | ให้เว็บยังใช้งานได้ระหว่างรอ และขอดูผลทีละชุด |

นี่คือเป้าหมายพัฒนา ส่วนที่ยังไม่ได้ลองรันยังไม่ถือว่าเสร็จ

## ผู้ใช้ต้องทำอะไรได้

1. เลือกโฟลเดอร์หรือไดรฟ์ Windows ในเครื่อง แล้วกดสแกน
2. เห็นจำนวนไฟล์และโฟลเดอร์ที่อ่านไปแล้ว ระหว่างที่โปรแกรมทำงาน
3. กางและพับโฟลเดอร์ทางซ้าย เลือกแล้วดูไฟล์และโฟลเดอร์ข้างในทางขวา
4. ดูชื่อ ขนาดเนื้อหาไฟล์ และพื้นที่ที่ไฟล์ใช้บนดิสก์
5. กด “แสดงเพิ่มเติม” เมื่อมีรายการต่อ และกดเปิดตำแหน่งไฟล์ใน Windows ได้
6. ยกเลิกการสแกนได้ และเห็นข้อความเมื่ออ่านไฟล์บางรายการไม่ได้

ปุ่มทุกปุ่มต้องบอกผู้ใช้ได้ว่ากำลังทำอะไร ทำสำเร็จ หรือเกิดปัญหา

## แสดงโฟลเดอร์มากแค่ไหน

เริ่มเปิดโฟลเดอร์ให้เห็น 2 ชั้นเพื่อให้หน้าไม่แน่น แต่ผู้ใช้กางต่อได้ตามรายการที่อ่านพบจริง ไม่ตัดทิ้งที่ชั้น 6

โหลดลูกของโฟลเดอร์ครั้งละ 50 รายการ ถ้ายังเหลือให้มีปุ่ม “แสดงเพิ่มเติม” ฝั่งซ้ายแสดงโฟลเดอร์ ฝั่งขวาแสดงรายการทั้งหมดรวมไฟล์และลิงก์ที่ข้ามการอ่าน

เมื่อได้ผลครบ ให้เรียงจากรายการที่ใช้พื้นที่บนดิสก์มากไปน้อย รายการที่วัดไม่ได้อยู่ท้าย ถ้าขนาดเท่ากันให้เรียงชื่อต่อ ระหว่างอ่านยังไม่เสร็จให้บอกว่า “กำลังคำนวณ” และดึงรายการใหม่เมื่อสแกนเสร็จ

## ตัวเลขต้องหมายถึงอะไร

| ชื่อที่ใช้ | ความหมาย | อ่านค่าจากไหน |
| --- | --- | --- |
| ขนาดเนื้อหาไฟล์ (Logical Size) | จำนวนไบต์เนื้อหาไฟล์ตามที่ระบบรายงาน | ส่วน C อ่านจากข้อมูลไฟล์ |
| พื้นที่ที่ไฟล์ใช้บนดิสก์ (Allocated Size) | จำนวนไบต์ที่ Windows รายงานว่าไฟล์ใช้บนดิสก์ | ส่วน Python ขอข้อมูลจาก Windows |
| ขนาดรวมของโฟลเดอร์ | รวมไฟล์ที่อ่านได้ภายในโฟลเดอร์นั้น | ส่วน Python รวมผล |

ถ้าอ่านค่าไม่ได้ ให้แสดง “ไม่ทราบ” ถ้าอ่านได้ไม่ครบ ให้แสดง “ผลบางส่วน” พร้อมบอกปัญหา ห้ามแทนค่าที่ไม่ทราบด้วยศูนย์หรือค่าประมาณ

ยอดรวมไฟล์อาจไม่เท่าพื้นที่ใช้ทั้งหมดของไดรฟ์ เพราะบางไฟล์เข้าไม่ถึง และระบบยังใช้พื้นที่จัดเก็บข้อมูลอื่นด้วย นอกจากนี้ไฟล์เดียวอาจมีหลายชื่อให้เข้าถึง ซึ่งแผนนี้อาจนับซ้ำตามชื่อ ต้องอธิบายข้อจำกัดนี้

นำการ์ด Slack Space ที่คำนวณจากสูตรเดิมออกจากผลส่งงาน เพราะส่วนต่างระหว่างขนาดสองแบบไม่ได้แปลว่าเป็นพื้นที่เสียเปล่าเสมอ เช่น ไฟล์ที่บีบอัดอาจใช้พื้นที่น้อยกว่าขนาดเนื้อหา

## เมื่อสแกนทั้งไดรฟ์

- โปรแกรมเริ่มอ่านไฟล์แล้วให้หน้าเว็บใช้งานต่อได้ มีปุ่มยกเลิก
- เว็บขอความคืบหน้าทุก 2 วินาที โดยบอกจำนวนรายการที่อ่านแล้ว ไม่เดาเปอร์เซ็นต์เมื่อยังไม่รู้จำนวนทั้งหมด
- ให้มีงานสแกนทั้งไดรฟ์พร้อมกันได้หนึ่งงาน
- เก็บผลในเครื่อง แล้วส่งเฉพาะชุดที่ผู้ใช้กำลังดู เพื่อไม่ให้เบราว์เซอร์แบกรายการทั้งหมด
- เมื่ออ่านไม่ได้หรือข้ามลิงก์ ให้เก็บจำนวนและเหตุผลไว้แสดง
- ตอนนำเสนอสดใช้โฟลเดอร์ย่อยที่รอไม่นาน ส่วนผลทั้งไดรฟ์สแกนไว้ก่อนบน Windows เครื่องเดียวกัน

## รายละเอียดสำหรับคนเขียนโปรแกรม

รายละเอียดชื่อข้อมูลและตัวอย่างอยู่ใน [CONTRACT.md](CONTRACT.md) คำต่อไปนี้เป็นชื่อเครื่องมือที่เลือกใช้:

| คำในโค้ด | ความหมายในงาน |
| --- | --- |
| POSIX | มาตรฐานคำสั่งที่ส่วน C ใช้อ่านรายการและข้อมูลไฟล์บน Linux |
| NDJSON | ส่งข้อมูลเป็นข้อความทีละบรรทัด แต่ละบรรทัดแทนหนึ่งรายการหรือหนึ่งเหตุการณ์ |
| API | คำขอที่หน้าเว็บส่งให้ Python เช่น ขอเริ่มสแกนหรือขอดูรายการ |
| SQLite | ที่เก็บผลสแกนเป็นไฟล์ภายในเครื่อง ไม่ต้องติดตั้งเครื่องแม่ข่ายฐานข้อมูลเพิ่ม |
| localhost / 127.0.0.1 | เปิดใช้เว็บได้เฉพาะในคอมเครื่องที่รันโปรแกรม |
| `GetCompressedFileSizeW` | คำสั่ง Windows ที่ใช้ถามพื้นที่ของไฟล์บนดิสก์ |

C ใช้ `opendir/readdir/lstat/closedir` อ่านรายการและปิดสิ่งที่เปิดใช้ ตรวจข้อผิดพลาด ไม่ตามลิงก์ ไม่อ่านวน และไม่เดินออกนอกไดรฟ์ที่เลือก Python แปลงตำแหน่งโฟลเดอร์ระหว่าง Windows กับ WSL และตรวจว่ารายการที่ได้รับอยู่ภายในโฟลเดอร์ที่เลือก

เก็บผลเพิ่มทีละชุดใน SQLite และจัดให้ค้นรายการลูกของโฟลเดอร์ได้เร็ว เก็บผลล่าสุดต่อโฟลเดอร์/ไดรฟ์ พร้อมวิธีล้างผลเก่าที่ไม่ลบไฟล์จริงของผู้ใช้ รายละเอียดเหล่านี้เป็นงานของปวริศช์

ก่อนนำเสนอ ให้เก็บส่วนแสดงผลที่เว็บต้องใช้ไว้ในโปรเจกต์ เพื่อเปิดเว็บได้แม้ไม่มีอินเทอร์เน็ต

## ลองแล้วดูอย่างไรว่าผ่าน

ลองโฟลเดอร์ว่าง โฟลเดอร์ลึก 8 ชั้น โฟลเดอร์ที่มีลูก 60 รายการ ชื่อไทย ชื่อมีช่องว่าง ไฟล์ขนาดศูนย์ และไฟล์ขนาดใหญ่ ตรวจว่าดูรายการได้ครบและขนาดตรงกับตัวอย่าง

ลองกรณีอ่านไฟล์ไม่ได้ ลิงก์ชี้วน กดยกเลิก และกดเปิดตำแหน่งไฟล์ ต้องมีข้อความตรงกับสิ่งที่เกิดขึ้น

ลองกดและเลื่อนเว็บขณะสแกน ตรวจว่าดูสถานะ ดูรายการ และยกเลิกได้ งานส่งใช้ C → Python → เว็บแนวทางเดียว ไม่ทำ benchmark เปรียบเทียบกับต้นแบบ ไม่กำหนดให้วัดความเร็ว จำนวนรายการต่อวินาที หรือหน่วยความจำ เวลาที่แสดงในสถานะมีไว้บอกผู้ใช้ว่างานทำมาแล้วนานเท่าไร

งานค้นหา ส่งออกข้อมูล แผนภาพแบบพื้นที่สี่เหลี่ยม ค้นหาไฟล์ซ้ำ และลบไฟล์ยังอยู่นอกขอบเขตงานที่วางไว้
