## ทุกคนต้องอธิบายภาพรวมได้

1. ผู้ใช้เปิดเว็บบน Windows เลือก path; Python สั่ง C scanner ใน WSL ให้เดิน directory ด้วย POSIX APIs
2. C ส่งข้อมูลรายการ/ข้อผิดพลาดทีละบรรทัด; Python วัด Allocated ของไฟล์ Windows และเก็บผลเพื่อให้เว็บเปิด tree ทีละหน้า
3. Logical, Allocated และยอดใช้พื้นที่ทั้งไดรฟ์เป็น **คนละความหมาย**; ถ้าอ่านไม่ได้ต้องบอก partial
4. เว็บเดิมเป็นต้นแบบ Python/Win32 ส่วนใดที่ยังไม่ได้ทดสอบจริงห้ามตอบว่า “เสร็จแล้ว”

## ตรวจงานก่อนกล่าวอ้างต่ออาจารย์

- คำว่า **เร็ว** ต้องมีเวลาจริง จำนวนรายการและเครื่องที่วัด; จำนวน worker หรือ `FIND_FIRST_EX_LARGE_FETCH` อย่างเดียวไม่ใช่หลักฐาน
- คำว่า **พื้นที่จริง** ต้องชี้ไปยัง API ที่วัดและผลเทียบไฟล์ตัวอย่าง; สูตร cluster/resident แบบคงที่ของต้นแบบเป็นเพียงแบบจำลอง
- คำว่า **tree ครบ** ต้องทดลอง path ลึกเกิน 6 ชั้นและโฟลเดอร์ที่มีลูกเกิน 50 รายการ
- คำว่า **ปุ่มใช้ได้** ต้องกดจริงทั้ง success/error บนเครื่องเดโม โดยเฉพาะ Scan, Cancel, Reveal และแสดงเพิ่มเติม
- คำว่า **ไม่ค้าง** ต้องทดสอบขณะสแกนไดรฟ์ ไม่ใช่เพียงโฟลเดอร์เล็ก
- หาก WSL, Windows API หรือไฟล์บางรายการใช้ไม่ได้ ให้บันทึกข้อจำกัดตรง ๆ และแสดง partial
