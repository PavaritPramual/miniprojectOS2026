# อ่านก่อนซ้อมอธิบายงาน

ทุกคนควรอธิบายภาพรวมนี้ได้:

“ผู้ใช้เลือกโฟลเดอร์จากหน้าเว็บ โปรแกรมอ่านรายการไฟล์และขนาด แล้วแสดงเป็นโฟลเดอร์ที่กางดูข้างในได้ เราจึงเห็นว่าโฟลเดอร์ไหนใช้พื้นที่มาก”

ทำทั้งหมดบน Windows เครื่องเดียวได้ ส่วนภาษา C ตามแผนจะรันใน WSL ซึ่งเปิด Linux ภายใน Windows แล้ว Python ส่งผลให้หน้าเว็บ

## แต่ละคนเตรียมอะไร

| สมาชิก | เปิดส่วนใดให้ดู | อธิบายให้ได้ |
| --- | --- | --- |
| ศรัณย์ | โค้ด C ที่อ่านไฟล์ | เริ่มอ่านจากไหน เข้าโฟลเดอร์ย่อยอย่างไร และทำอย่างไรเมื่ออ่านไม่ได้ |
| ปวริศช์ | ส่วนเรียก C และรวมขนาด | ข้อมูลเดินทางมาถึงเว็บอย่างไร ขนาดคิดจากอะไร และผลที่วัดจริงเป็นเท่าไร |
| ธีรเมธ | หน้าเว็บและปุ่ม | เลือกโฟลเดอร์อย่างไร ดูรายการเพิ่มอย่างไร และรู้ได้อย่างไรว่างานเสร็จ |

## คำตอบตัวอย่าง

**ทำไมใช้ภาษา C?** เอกสารวิชาเน้นการเขียนโปรแกรมที่เรียกใช้คำสั่งเกี่ยวกับระบบปฏิบัติการตามมาตรฐาน POSIX เราใช้ C ทำส่วนอ่านรายการและข้อมูลไฟล์ ส่วนเว็บช่วยให้ผู้ใช้ดูผลได้สะดวก

**ทำไมใช้ WSL?** เพื่อรันส่วน C ที่ใช้คำสั่งแบบ Linux โดยยังทำงานและเปิดเว็บอยู่บน Windows เครื่องเดียวกัน

**ทำไมมีขนาดสองค่า?** ค่าแรกคือขนาดเนื้อหาไฟล์ อีกค่าคือพื้นที่ที่ Windows รายงานว่าไฟล์ใช้บนดิสก์ ทั้งสองค่าอาจต่างกัน

**ถ้าบางไฟล์อ่านไม่ได้?** โปรแกรมควรแจ้งว่าอ่านได้เพียงบางส่วน และบอกจำนวนหรือรายการที่มีปัญหา

**รู้ได้อย่างไรว่าโปรแกรมเร็ว?** ต้องลองสแกนแล้วจับเวลา บอกจำนวนไฟล์และเวลาที่วัดได้จริง หากยังไม่เคยวัดก็ยังสรุปไม่ได้

**โฟลเดอร์ที่เห็นครบหรือยัง?** ลองกับโฟลเดอร์ที่รู้จำนวนไฟล์อยู่แล้ว รวมถึงโฟลเดอร์หลายชั้นและที่มีรายการเกินหนึ่งหน้า แล้วตรวจว่าดูได้ครบ
