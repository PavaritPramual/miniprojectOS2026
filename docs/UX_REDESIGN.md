# ปรับ UX ของเมืองไฟล์

ปรับวันที่ 12 ตุลาคม 2569 จากข้อเสนอแนะผู้ใช้ที่ตรวจเว็บจริง

## หลักที่ศึกษาก่อนแก้

- [NN/g — Visibility of System Status](https://www.nngroup.com/articles/visibility-system-status/) ระบบต้องตอบกลับให้ผู้ใช้เห็นว่ารับคำสั่งแล้ว กำลังทำอะไร และได้ผลอย่างไร จึงเพิ่มสถานะค้นหาและบันทึกเหตุการณ์จริงจาก API
- [NN/g — Tooltip Guidelines](https://www.nngroup.com/articles/tooltip-guidelines/?lm=help-and-documentation&pt=youtubevideo) ข้อมูลหรือคำสั่งสำคัญไม่ควรมีเฉพาะ tooltip ที่หายเมื่อเลื่อนเมาส์ จึงใช้แผงรายละเอียดที่ค้างหลังเลือกไฟล์ และให้ tooltip ใช้ช่วยระบุชื่อเท่านั้น
- [NN/g — Heuristic Summary](https://media.nngroup.com/media/articles/attachments/Heuristic_Summary1-compressed.pdf) ลดข้อมูลที่ไม่เกี่ยวกับงานขณะนั้นและช่วยให้เห็นตัวเลือกได้ จึงใช้เมืองเป็นหน้าหลัก รายการเป็นมุมมองทางเลือก และเก็บคำอธิบายในส่วนที่เปิดอ่านเอง
- [SQLite — LIKE/ESCAPE](https://sqlite.org/lang_expr.html#like) และ [Snapshot Isolation](https://sqlite.org/isolation.html) ใช้ค้นชื่อ/path ด้วย parameters อักขระ `%` และ `_` เป็นตัวอักษรจริง และอ่านจำนวนกับรายการใน transaction เดียวกัน

## ผลที่ผู้ใช้เห็น

1. มีเมืองหรือรายการทีละมุมมอง ไม่มีกราฟแท่ง ตาราง และ tree วางต่อกันทั้งหมด
2. คลิกอาคารแล้วชื่อเต็ม ขนาด และปุ่มเปิดตำแหน่งค้างอยู่ด้านข้าง เมาส์เลื่อนออกได้โดยข้อมูลไม่หาย
3. อาคารมีหน้าต่าง ป้ายชนิดไฟล์ และฐานแปลง/ถนน รายการเล็กมีป้ายโยงชื่อ เมื่อค้นแล้วเลือกจะซูมและมีหมุดชื่อกำกับ
4. ป้ายโยงแสดงได้ 12 รายการต่อภาพเพื่อไม่ให้ชื่อทับกัน รายการอื่นยังค้นจากฐานข้อมูลและเลือกดูชื่อเต็มได้ อาคารที่เลือกมีหมุดเสมอเมื่อมีพื้นที่สำหรับวาด
5. ค้นได้จากผลสแกนทั้งชุดใน SQLite ไม่จำกัดเฉพาะไฟล์ 50 รายการที่โหลดบนเมือง รองรับชื่อภาษาไทย path แบบ Windows และผลค้นหาทีละ 50 รายการ
6. เห็นข้อความกำลังค้นหา จำนวนที่พบ ไม่พบผล และข้อผิดพลาด บันทึกการทำงานแสดงคำสั่งเริ่มสแกน จำนวนไฟล์/โฟลเดอร์ที่อ่าน การโหลดข้อมูล การค้นหา และการยกเลิกจริง ไม่สร้างเปอร์เซ็นต์หรือชื่อไฟล์ที่ scanner ไม่ได้รายงาน
7. หน้าเว็บไม่มีโหมดข้อมูลทดลองและไม่มีประวัติ localStorage ใช้เปิดผลล่าสุดจากฐานข้อมูลจริง หรือ URL `/?scan=...` ผล sample ถูกปฏิเสธ

หน้าต่างและรายละเอียดอาคารเป็นการตกแต่ง ไม่ได้ใช้แทนจำนวนไฟล์หรือ metadata พื้นที่ฐานยังอ้างขนาดที่วัดได้ ความสูงใช้สเกล log ไม่ใช่ความสูงต่อไบต์

## การตรวจรับ

ใช้ `tools/ux-city-uat.cjs` กับ Windows Python และ C ใน WSL จริง ตรวจตัวควบคุม หน้าต่างอาคาร ชื่อไฟล์เล็ก การเลือกด้วยเมาส์ แผงที่ค้าง การค้นไฟล์นอกหน้าที่โหลด log ผลค้นหา 50+10 การสลับเมือง/รายการ หน้าจอมือถือ การเปิดตำแหน่ง และการยกเลิก/เริ่มใหม่

ใช้ `tests/test_search.py` ตรวจ pagination, scan isolation, Unicode/null, wildcard literal และ path แบบ Windows ชุดทดสอบเตรียมข้อมูลภายในเพื่อทดสอบระบบ ส่วนหน้าใช้งานส่งข้อมูลจาก C จริงเท่านั้น

หลักฐานรุ่นก่อนใน `FILE_CITY_UAT.md` และกราฟเดิมเป็นประวัติของรุ่นก่อน ไม่ใช้ยืนยัน UX รุ่นนี้ โค้ด/ข้อมูลทดลองรุ่นเดิมอยู่ `fixtures/archive/ui-prototype/`

สไลด์ Canva/PPTX/PDF และเว็บอัปเดตหน้า 2 และ 7 เป็นเมืองไฟล์แล้ว หน้า 8 ใช้ผลตรวจล่าสุด บทพูดและลำดับเดโมตรงกับ UX ใหม่ ยังต้องอัดวิดีโอเดโมและคลิปสุดท้าย
