Directory, metadata และ IPC

  • Directory traversal: เดินรายการโฟลเดอร์
  • Metadata: อ่านชนิดและขนาดโดยไม่อ่านเนื้อหาทั้งไฟล์
  • IPC: process ของ Python กับ C ส่งข้อมูลผ่าน pipe
  • POSIX API ใน libc ขอใช้บริการของ kernel
คำพูดประกอบและแหล่งอ้างอิง

opendir/readdir/closedir เป็นฟังก์ชัน libc ไม่ควรบอกว่าทุกชื่อเป็น kernel syscall โดยตรง lstat อ่าน metadata ของตัวลิงก์โดยไม่ตามปลายทาง Scanner ต้องเช็ก errno และปิด directory stream ใช้ strace กับ C ที่รันจริงเพื่อยืนยัน syscall บนเครื่องนำเสนอ ขณะนี้ checkout ยังไม่มี scanner C รุ่นส่งงาน แหล่งอ้างอิง: https://man7.org/linux/man-pages/man3/readdir.3.html และ https://man7.org/linux/man-pages/man2/stat.2.html

  • 3 C → OS: อ่าน directory / metadata ส่ง NDJSON
  • 4 Python: วัด Allocated บน Windows และเก็บ SQLite
  • 5 Browser: ขอ status ทุก 2 วินาที และลูกครั้งละ 50

Python bridge และ SQLite รวมใน checkout แล้ว ทดสอบ Browser → Python → SQLite ด้วยข้อมูลทดสอบ ส่วน C/WSL และ Windows ต้องยืนยันบนเครื่องนำเสนอ POST /api/scans คืน id ก่อน scan จบ จากนั้นหน้าเว็บขอ GET /api/scans/{id} และ children Python ต้องแปลง path จาก D:\demo เป็น /mnt/d/demo ตรวจ relativePath และแยก stderr จาก stdout JSON เป็นรูปแบบข้อมูล HTTP กับ pipe เป็นช่องทางสื่อสาร แหล่งอ้างอิง: docs/CONTRACT.md, docs/UI_HANDOFF.md และ https://docs.python.org/3/library/subprocess.html

Logical กับ Allocated

  • Logical: ขนาดเนื้อหาไฟล์จาก metadata ของ C
  • Allocated: พื้นที่บนดิสก์จาก Windows API
  • ไฟล์บีบอัดอาจใช้พื้นที่น้อยกว่าขนาดเนื้อหา
  • null = ไม่ทราบค่า 0 = วัดได้ศูนย์
  • ยอดตาม path อาจนับ hard link ซ้ำ
คำพูดประกอบและแหล่งอ้างอิง

ไม่ใช้สูตรปัด cluster แทนค่าที่วัด และไม่เรียก Allocated ลบ Logical ว่า Slack เสมอ UI แสดงค่าจาก backend โฟลเดอร์ต้องรวมจากผลทั้งโฟลเดอร์ ไม่ใช่แค่ 50 แถวบนจอ ยอด root และโฟลเดอร์ที่เลือกอ่านจาก children.folder ตาม API ล่าสุด หลังสแกนจบจะโหลด metadata ใหม่ ค่า 0 แสดง 0 B ส่วน null แสดงไม่ทราบ ตอนนำเสนอให้ปวริศช์แสดงไฟล์ที่ตรวจเทียบ Windows จริงหนึ่งไฟล์ ปัจจุบันยังไม่มีหลักฐานนั้นในชุดส่งนี้ แหล่งอ้างอิง: https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getcompressedfilesizew และ docs/SPEC.md
